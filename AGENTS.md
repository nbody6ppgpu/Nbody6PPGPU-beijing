# AGENTS.md

**NBODY6++GPU** (Beijing branch, Rainer Spurzem's team): direct N-body star cluster evolution code, Hermite + block time step; MPI + OpenMP + GPU (CUDA/HIP) + SIMD; includes SSE/BSE stellar evolution, KS-regularised binaries, Galactic tidal field; HDF5/binary/ANSI output. GPUs give a clear speedup only for N > 50,000. Core is Fortran 77 (`src/Main/`), GPU code is `.cu`, SIMD code is `.cpp`.

## Must-know constraints

- `include/params.h` is generated by configure and must not be committed; to change the particle-number mapping, edit `configure.ac`.
- `configure` is a generated file committed to the repo: after changing `configure.ac` or `macro/*.m4`, you must run `tool/regen-configure.sh` to regenerate it and commit it together (CI compares byte-for-byte); do not run `autoconf` directly.
- Standard fix for out-of-memory: `--enable-mcmodel=large`, `export OMP_STACKSIZE=4096M`, `ulimit -s unlimited`.
- `KZ(7) >= 4` gives wrong output, use `KZ(7) <= 3`; `--enable-simd=no` automatically disables OpenMP.

## Development workflow

1. `git checkout -b feature/your-feature`
2. After changes, run `./configure [options]`, then `make clean && make -j`
3. Run a quick test with `examples/input_files/N10k_noDat10.inp` and check the output files are complete
4. Commit and push:
   ```bash
   git add .
   git commit -m "Descriptive commit message"
   git push origin feature/your-feature
   ```
