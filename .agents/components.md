# Core Components and Source File Map

### 1 Main program loop (`src/Main/nbody6.F`)
- Main integration loop
- Time-step management
- Output control
- MPI process coordination

### 2 Force computation modules
| Module | Files | Function |
|------|------|------|
| **Regular force** | `regcor_gpu.F`, `nbint.F` | Neighbour lists, regular force correction |
| **Irregular force** | `fpoly*.F` | Irregular force polynomial extrapolation |
| **GPU acceleration** | `gpunb.gpu.cu`, `gpupot.gpu.cu` | GPU potential and force computation |
| **SIMD optimisation** | `pot.{sse,avx}.cpp`, `reg.{sse,avx}.cpp` | CPU vectorised force computation |

### 3 Binaries and regularisation
| Type | Key files | Description |
|------|----------|------|
| **KS binaries** | `ksinit.F`, `kspreg.F`, `ksreg.F`, `ksterm.F` | Kustaanheimo-Stiefel regularisation method |
| **Chain (few-body) subsystems** | `chain.f`, `chlist.f`, `chinit.f` | Three-body and higher-order systems |
| **Binary evolution** | `binev.f`, `binpop.F`, `tides.f` | Binary evolution, tidal circularisation |

### 4 Stellar evolution
| Component | Files | Model |
|------|------|------|
| **Single-star evolution** | `hrplot.F`, `star.f` | Hurley et al. SSE |
| **Binary evolution** | `binev.f`, `mix.f` | Hurley et al. BSE |
| **Common envelope** | `comenv.f` | Envelope evolution physics |
| **Giant physics** | `giant.f`, `giant2.f`, `giant3.f` | Mass loss in giant phases |
| **Mergers** | `coal.f`, `merge.f`, `merge2.f` | Collision and merger events |
| **GW recoil kick** | `kickGW.f`, `recoil.f` | Recoil velocity after a gravitational-wave merger |

### 5 Milky Way potential
| File | Function |
|------|------|
| `mwpotinit.F` | MWPotential2014 initialisation |
| `fmwpot.f` | Milky Way potential force computation |
| `pmwpot.f` | Milky Way potential energy computation |
| `MWpotential.f` | Utility functions (src/Tools) |

### 6 Input/output
| Type | Files | Format |
|------|------|------|
| **Standard output** | `output.F` | Plain text or Fortran binary format |
| **HDF5 output** | `custom_output.F`, `custom_output_facility.F` | HDF5 snapshot files |
| **Diagnostic output** | `energy.F`, `lagr.f`, `binout.f`, `stdout` | Energy, Lagrangian radii, binary statistics |

# Repository Layout and Tech Stack

- `src/Main/`: main source (~500+ Fortran/CUDA files); `src/Tools/`: utility programs (e.g. `MWpotential.f`)
- `include/`: headers and parameter configuration (`common6.h` global common blocks and physical constants, `kspars.h` KS parameters, `cuda_*.h` GPU interfaces; `params.h` is generated by configure and not under version control)
- `extra_inc/` (extra includes for MPI, CUDA), `build/` (build output), `macro/` (Autoconf M4), `config.examples/`, `configure.ac`, `Makefile.in`
- `examples/`: example inputs and Jupyter notebooks; `doc/`: manual (git submodule, pointing to nbody6ppgpu/nb6-manual, pinned commit)

| Language | Purpose | Key files |
|------|------|----------|
| Fortran 77 (~400+) | Core N-body integration, stellar evolution | `nbody6.F`, `intgrt.F`, `setup.F`, `hrplot.F` |
| CUDA C++ (3) | GPU force computation | `gpunb.gpu.cu`, `gpupot.gpu.cu`, `gpunb.velocity.cu` |
| C++ (~15) | SIMD (SSE/AVX) | `pot.sse.cpp`, `reg.avx.cpp`, `irr.sse.cpp` |
| Python / Shell | Data analysis, input conversion / build scripts | `restore_mtime.py`, `configure`, `@input-transform` |

Toolchain: GNU Autoconf/Automake; gfortran, NVCC (CUDA 10.0+), g++; OpenMPI, OpenMP; HDF5.
